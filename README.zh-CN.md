# Peach 路线图

Peach 的开发计划与交付进度。

[需求看板](https://github.com/orgs/peach-mitao/projects/7/views/1) · [路线图](https://github.com/orgs/peach-mitao/projects/7/views/3) · [任务列表](https://github.com/peach-mitao/peach-roadmap/issues) · [English](README.md)

## 规划

- **统一看板**：用户反馈与维护者任务共用一个公开项目。
- **优先级**：P0 紧急、P1 优先、P2 常规、P3 低优先级。
- **计划阶段**：近期、后续与探索表示计划，不构成交付日期承诺。

[问题反馈与功能建议](https://github.com/peach-mitao/peach/issues/new/choose)在应用仓库提交；个人馆藏、账号与设备操作保留在私有清单。

## 交付

实现代码和 PR 放在 [Peach 主仓库](https://github.com/peach-mitao/peach)。PR 正文单独关联任务，例如：`Refs peach-mitao/peach-roadmap#1`。也支持完整 Issue 地址与 GitHub 的 Issue 关联。

PR 合入后，开放任务进入待验证；下载制品实际包含实现后填写发布版本，完成验收再关闭 Issue。应用仓库事件触发同步，并每 6 小时检查；本仓库不保存看板凭据。

同步细节见[看板规则](https://github.com/peach-mitao/peach/blob/master/docs/PROJECT_BOARD.md)，任务范围与验收判据见各 Issue。
